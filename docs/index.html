Animation system

3 tiers — free to professional

APEX auto-selects the best available tier on every run. No manual switching.

Tier 1 — Narrated Slideshow

ALWAYS ACTIVE · FREE FOREVER

Works immediately with zero setup. AI-generated cartoon images per scene with voice narration and Ken Burns zoom effects.

  • Pollinations.ai — unlimited free AI image generation
  • gTTS — free voice narration (or Google WaveNet for human quality)
  • Ken Burns motion effects — slow pan and zoom per scene
  • On-screen captions and branded thumbnails
  • Real .mp4 — uploadable to YouTube immediately
  • Static images — not moving animation
🆓

Tier 2 — Manim 2D Animation

FREE FOREVER · pip install manim

Smooth 2D animated scenes — the same animation engine used by 3Blue1Brown (4M+ subscribers). Free forever, no GPU needed.

  • Moving characters — Trishul, Sandy, Libhu as animated shapes
  • Speech bubbles, scene transitions, animated text
  • Runs on any laptop — no GPU required
  • Same quality as 3Blue1Brown YouTube channel
  • APEX generates all Manim code automatically
pip install manim
winget install MiKTeX.MiKTeX  # Windows only
# Restart APEX — Manim activates automatically

Tier 3 — Kling AI / Pika Labs / Runway ML

PAID · ₹1,200-1,500/month · Real cartoon animation

Real animated cartoon clips per scene. Characters actually move. Near Cartoon Network quality. Add one API key to activate.

  • Real animated clips — characters move naturally
  • 5-10 seconds of animation per scene
  • Kling AI — 66 free clips on signup (enough to test ~11 episodes)
  • APEX sends scene descriptions → receives animated .mp4 clips
  • All clips stitched automatically into final video

Quick start

Running in 3 commands

One-shot installer handles everything. Python is the only prerequisite.

# 1. Clone
git clone https://github.com/sachiii143/apex-youtube-agent.git
cd apex-youtube-agent

# 2. Run one-shot installer
# Installs: venv, all packages, ffmpeg, Ollama, Playwright
# Asks for: free API keys, YouTube OAuth (guided)
PowerShell -ExecutionPolicy Bypass -File "run_nova.ps1"

# 3. Browser opens at http://127.0.0.1:5000
# Nova greets you by voice. Say "make a video" to start.
